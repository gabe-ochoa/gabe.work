How I use AI

I want to spend less time collecting the work and more time deciding what to do about it.

That has led me to build tools around the parts of my day where information is scattered or a script needs a little judgment. The morning report brings the work together. Smaller command-line tools use a model when the answer depends on what the words mean.

What I’m trying to get right

The useful part is deciding where interpretation belongs and where I need an exact check. A model can help me read a situation, but a test result comes from running the test. Permission comes from me. Keeping those boundaries visible makes these tools easier to trust and easier to fix.
